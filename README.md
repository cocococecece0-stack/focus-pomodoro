# Фокус

Минималистичный таймер Pomodoro для Android на Kotlin + Jetpack Compose.

## Что умеет

- Цикл 25 мин фокуса / 5 мин перерыва, после каждых 4 сессий — длинный отдых на 15 мин
- Круговой прогресс, старт/пауза/сброс, ручной выбор режима
- Счётчик завершённых сессий за сегодня с сохранением в DataStore (сбрасывается на новый день)
- Material 3, динамические цвета на Android 12+, тёмная тема
- Без интернета и лишних разрешений

## Сборка

APK собирается в GitHub Actions при каждом пуше:

1. Открыть вкладку **Actions** → последний запуск **Build**
2. Скачать артефакт **focus-debug-apk**
3. Установить `app-debug.apk` на устройство (разрешить установку из неизвестных источников)

Локальная сборка (нужен Android SDK):

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.

## Стек

Kotlin 2.0, AGP 8.7, Gradle 8.11, Compose BOM 2024.10, minSdk 26, targetSdk 35.
